# SF(49398) Регистрация товаров ( открытие магазина)

Для регистрации товаров заполняем обязательные поля: Поставщик, Магазин. Далее делаем импорт спецификации из Excel.

{% stepper %}
{% step %}
### Подготовка данных в Excel

В Excel вводите или вставляете спецификацию (перечень товаров и нужные поля). Скопируйте подготовленные строки в буфер обмена.

![Спецификация в Excel](<../../.gitbook/assets/image (605)>)
{% endstep %}

{% step %}
### Импорт из Excel в систему

Нажмите «Импорт из Excel» и вставьте данные из буфера обмена в появившееся поле. Проверьте корректность сопоставления колонок и завершите импорт.

![Импорт из Excel](<../../.gitbook/assets/image (606)>)
{% endstep %}
{% endstepper %}
