# SF (1216) Скидка оприходование товара

### Документ может быть создан в следующих случаях

#### Исправление себестоимости по существующим товарам в остатке (217)

Существуют два способа:

{% stepper %}
{% step %}
#### Способ 1 — распределение по остаткам

* a) суммарное распределение\
  Во время выполнения действия "Формирование проводок (распределение сумм)" корректируется значение себестоимости для фигурирующих в остатке (217) товаров суммовым методом.
* b) количественное распределение\
  Действие "Формирование проводок (распределение кол-ва)" определяет значение себестоимости для фигурирующих в остатке (217) товаров количественно.
{% endstep %}

{% step %}
#### Способ 2 — при выполнении "Формирования проводок (тип2)"

* При выполнении "Формирования проводок (тип2) — проданные" пересчитается значение себестоимости на уже проданные товары.
{% endstep %}

### Расчёт значения себестоимости для уже проданного товара (711)

В данном случае проводки выглядят так:

* Dt 217 (711) Ct 521 (значение с минусом)
* Dt 534 Ct 521 (значение с минусом)

Корректировка будет распределена по партиям товара, пропорционально каждой партии в зависимости от стоимости. Если в столбце «количество» указанное число будет больше нуля, тогда сумма будет распределена на каждую единицу по стоимости на одну штуку, рассчитанной в документе согласно методу FIFO.
