# Импорт по группам.

Для ввода и регистрации инвойсов в базе данных используется документ (48113) Импорт по группам.

Документ состоит из трёх частей: шапочная часть и две табличные части.

Шапочная часть заполняется первой. Указываются: склад (магазин), таможня, поставщик, транспортировщик, валюта, брокер и сумма в транспортной валюте.

![](<../../.gitbook/assets/image (618)>)

В первом гриде вводятся данные из инвойса, относящиеся к товарной группе. После указания необходимых данных в первом гриде можно приступать к заполнению второго грида.

## Заполнение второго грида при вводе нового товара

Действие: Заполнить из документа Регистрация товаров (49398)

Если товар новый и был введён в базу из документа [SF=49398 Регистрация товаров](https://xwiki.una.md/bin/view/UNA/49398_factory), то вторую табличную часть первоначально заполняют с помощью действия "Заполнить из документа Регистрация товаров (49398)". Код документа регистрации товаров (49398) или список кодов указывается во вкладке "Информация" через запятую.

![](<../../.gitbook/assets/image (619)>)

После выполнения этого действия вторая табличная часть заполнится списком товаров из документа (49398) Регистрация товаров.

![](<../../.gitbook/assets/image (620)>)

## Действия (операции) в документе

{% stepper %}
{% step %}
### Привязать весь товар к первой группе

Привязывает список товаров из второго грида к первой группе из верхней табличной части.

После заполнения 1-го грида документа формируется соответствующее действие по расчёту себестоимости согласно заполненным данным в первом гриде.
{% endstep %}

{% step %}
### Экологический налог

Выполнит распределение затрат из первого грида во втором.\
В первом гриде вводятся данные из инвойса, относящиеся к товарной группе экологического налога. Для расчёта экологического налога есть отдельная инструкция: http://xwiki.una.md/bin/view/imp/taxa\_ecologica
{% endstep %}

{% step %}
### Рассчитать себестоимость — количество

Выполнит расчёт себестоимости по количеству товара. Сформированное действие заполнит соответствующие колонки.
{% endstep %}

{% step %}
### Рассчитать себестоимость — сумма

Выполнит расчёт себестоимости по сумме товара.
{% endstep %}

{% step %}
### Проводки

Создаст бухгалтерские записи в документе (48113) Импорт по группам.
{% endstep %}

{% step %}
### Обновить Price-list

Зафиксирует изменения в прайс-листе. Является завершением операций, проводимых в данном документе.
{% endstep %}

{% step %}
### Отменить обновление Price-list

Если нужно внести изменения, связанных с документом (48113) Импорт по группам, выполните это действие, внесите правки и повторно выполните действие "Проводки" (см. выше), затем зафиксируйте Price-list действием "Обновить Price-list".
{% endstep %}
{% endstepper %}

![](<../../.gitbook/assets/image (621)>)

Для каждой группы товаров вводим товары во 2-м гриде и выполняем действие "Рассчитать себестоимость" (по сумме или по количеству в зависимости от задачи), далее выполняем действие "Проводки".

Проверить проводки документа (48113) Импорт по группам можно с помощью универсального отчёта: http://xwiki.una.md/bin/view/UNA/UO\_VAMA
