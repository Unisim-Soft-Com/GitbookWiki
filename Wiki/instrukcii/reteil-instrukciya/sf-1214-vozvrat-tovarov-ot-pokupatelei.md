# SF (1214) Возврат товаров от покупателей

Для отражения операции возврата денежных средств за некачественный или неугодный покупателю товар используется документ (1214) Возврат товаров от покупателей:

![](<../../.gitbook/assets/image (607)>)

{% hint style="info" %}
Обязательно указывайте магазин, в котором проходила продажа.
{% endhint %}

Первоначально в документе указывается дата и затем заполняется титульная часть. Во вкладке "Информация" указывается номер чека, который предъявил покупатель:

![](<../../.gitbook/assets/image (608)>)

{% stepper %}
{% step %}
### Заполнение документа

1. Укажите дату.
2. Заполните титульную часть (обязательно — магазин).
3. Во вкладке "Информация" укажите номер чека, предъявленный покупателем.
{% endstep %}

{% step %}
### Заполнение товара по номерам чеков

Выберите одно из действий в меню "Действия на документы":

* Заполнить товар по номерам чеков — если продажа выполнялась на основном кассовом сервере.

![](<../../.gitbook/assets/image (609)>)

* Заполнить товар по номерам чеков с резервного сервера — если касса на момент продажи работала на резерве.

![](<../../.gitbook/assets/image (610)>)
{% endstep %}

{% step %}
### Редактирование списка товара

После заполнения по номерам чеков при необходимости отредактируйте список товара в чеке (удалите или скорректируйте позиции):

![](<../../.gitbook/assets/image (611)>)
{% endstep %}

{% step %}
### Проведение бухгалтерских записей

Выполните действие формирования бухгалтерских записей — либо кнопкой "Actiuni", либо выбрав соответствующее действие из списка:

![](<../../.gitbook/assets/image (612)>)

![](<../../.gitbook/assets/image (613)>)
{% endstep %}
{% endstepper %}
