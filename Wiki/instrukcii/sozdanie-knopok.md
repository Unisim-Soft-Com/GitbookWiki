### Кнопка Cartela

![](<../.gitbook/assets/image (464)>)

В свойстве Caption запишите имя кнопки, например "Cartela":

![](<../.gitbook/assets/image (466)>)

![](<../.gitbook/assets/image (468)>)

Чтобы открыть карточку (cartela) при нажатии кнопки и передать параметр nrdoc:

* В свойстве Params нажмите многоточие и в открывшемся окне введите:

```
TargetType=cartela
TargetSection=ATTR_ORD_ADD
nrdoc=_nrdoc
MainTA=1
```

![](<../.gitbook/assets/image (470)>)

Это указывает, что по кнопке откроется карточка с секцией ATTR\_ORD\_ADD, и в форму передастся nrdoc=\_nrdoc (значение берётся из запроса для панели, на которой расположена кнопка). Подтвердите изменения (галочка) и сохраните документ.

После нажатия на кнопку будет открыта карточка:

![](<../.gitbook/assets/image (472)>)

### Кнопка Form

![](<../.gitbook/assets/image (474)>)

В Caption укажите имя кнопки, например "Form":

![](<../.gitbook/assets/image (476)>)

Чтобы открыть форму по нажатию кнопки:

* В Params нажмите многоточие и введите:

```
TargetType=form
TargetSection=CURS
```

![](<../.gitbook/assets/image (478)>)

Это указывает, что по нажатию откроется форма с именем секции CURS. Подтвердите изменение и сохраните. После нажатия кнопки откроется форма с курсами:

![](<../.gitbook/assets/image (480)>)

{% hint style="info" %}
В конфигураторе, при выделенной форме, нажмите "Node Properties" → Section, чтобы посмотреть имя секции формы. ![](<../.gitbook/assets/image (482)>)
{% endhint %}

### Кнопка Action

![](<../.gitbook/assets/image (484)>)

В Caption укажите имя кнопки, например "Action":

![](<../.gitbook/assets/image (486)>)

Чтобы выполнить действие при нажатии кнопки:

* В Params нажмите многоточие и введите:

```
TargetType=doc.action
action_id=1
```

![](<../.gitbook/assets/image (488)>)

Это указывает, что по нажатию будет выполнено действие с id=1. Подтвердите и сохраните изменения.

Пример: у документа может быть действие "Генерирование бух. проводок" — именно оно выполнится при нажатии кнопки Action:

![](<../.gitbook/assets/image (490)>)

После выполнения документ с проводками примет вид:

![](<../.gitbook/assets/image (492)>)

### Кнопка Print

![](<../.gitbook/assets/image (494)>)

В Caption укажите имя кнопки, например "Print":

![](<../.gitbook/assets/image (496)>)

Чтобы открыть печатную форму при нажатии кнопки:

* В Params нажмите многоточие и введите:

```
TargetType=doc.print
TargetSection=2:0:ABSTRACT PRINT DOCUMENT (D):1:0:0:8
```

![](<../.gitbook/assets/image (498)>)

Это указывает, что будет построена печатная форма с указанным именем секции. Подтвердите и сохраните. В результате будет построена печатная форма (например: накладная):

![](<../.gitbook/assets/image (499)>)

Имя секции печатной формы можно посмотреть через Node Properties → Section в конфигураторе.

![](<../.gitbook/assets/image (500)>)
