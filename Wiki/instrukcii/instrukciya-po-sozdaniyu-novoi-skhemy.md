# Инструкция по созданию новой схемы

{% stepper %}
{% step %}
### Предварительные настройки

1. Подключиться посредством удаленного помощника (командная строка: mstsc) к серверу, на котором находится необходимая схема.
2. Запустить программу un4Versions.exe. Приложение находится в папке GOOD на локальном диске (интерфейс приложения un4Versions.exe – рис.1).
3. Посредством приложения un4Versions.exe подключиться к нужному серверу с правами супервизора. Для этого выполнить следующие действия:

* Выбрать вкладку "Настройки"

![](<../.gitbook/assets/image (444)>)

или пункт меню "Настройки подключения"

![](<../.gitbook/assets/image (445)>)

* В поле "сервер или ..." ввести имя сервера

![](<../.gitbook/assets/image (446)>)

* Если пароль на подключение к схеме с правами супервизора SYS/SYS, нажать кнопку "Подключиться"

![](<../.gitbook/assets/image (447)>)

* Если пароль другой, нажать "Подключиться с вводом пароля"

![](<../.gitbook/assets/image (448)>)

и ввести необходимый пароль.
{% endstep %}

{% step %}
### Экспорт рабочей схемы

Необходимо сделать экспорт имеющейся схемы с фильтром на данные. Выполнить следующие шаги:

1. Выбрать вкладку "DataPump"

![](<../.gitbook/assets/image (449)>)

или пункт меню "Экспорт/импорт схемы"

![](<../.gitbook/assets/image (450)>)

2. Во внутренних вкладках выбрать вкладку "Действия"

![](<../.gitbook/assets/image (451)>)

3. Ввести или выбрать из списка поле "Схема-источник" — это поле содержит название рабочей схемы, которую экспортируем.

![](<../.gitbook/assets/image (453)>)

4. Ввести или выбрать из списка поле "Oracle Directory". Если оставить поле пустым, по умолчанию берется директория оракла DATA\_PUMP\_DIR.

![](<../.gitbook/assets/image (455)>)

5. При необходимости откорректировать поле "Файл экспорта" (по умолчанию совпадает с именем схемы-источника)

![](<../.gitbook/assets/image (457)>)

6. Нажать кнопку "Скомпилировать ист." (необязательно).

![](<../.gitbook/assets/image (459)>)

7. Нажать кнопку "Создать таблицу объектов"

![](<../.gitbook/assets/image (461)>)

8. Выбрать вкладку "Фильтр на таблицы"

![](<../.gitbook/assets/image (463)>)

9. Нажать кнопку "Заполнить главные" (в нижней части окна)

![](<../.gitbook/assets/image (465)>)

10. Просмотреть и, если не установлен, поставить фильтр: галка "Контроль вручную"

![](<../.gitbook/assets/image (467)>)

11. Снова вернуться на вкладку "Действия".
12. Нажать кнопку "Экспорт по фильтру". Появится окно сообщений — дождаться успешного завершения процесса экспорта.

![](<../.gitbook/assets/image (469)>)

![](<../.gitbook/assets/image (471)>)

![](<../.gitbook/assets/image (473)>)
{% endstep %}

{% step %}
### Импорт новой схемы

Необходимо импортировать полученный файл в новую схему. Выполнить следующие шаги:

1. Подключиться к серверу импорта (туда, где будет стоять база). Если он на другом сервере — см. раздел "Предварительные настройки".
2. Если необходимо — снова заполнить поле "Схема-источник" (поле обязательно должно быть заполнено при импорте). Здесь указывается имя схемы, которая экспортировалась (без документов) для создания новой схемы.

![](<../.gitbook/assets/image (475)>)

3. В поле "Новая схема" ввести название (по умолчанию имя схемы-источника).

![](<../.gitbook/assets/image (477)>)

4. Нажать кнопку "Импорт всей схемы". Появится окно сообщений — дождаться успешного завершения процесса.

![](<../.gitbook/assets/image (479)>)

![](<../.gitbook/assets/image (481)>)

![](<../.gitbook/assets/image (483)>)

Примечание: как правило, процесс импорта завершается с ошибками. Ошибки можно посмотреть, нажав соответствующую кнопку в интерфейсе.

![](<../.gitbook/assets/image (485)>)

5. Обязательно нажать кнопку "Скомпилировать ист."

![](<../.gitbook/assets/image (487)>)
{% endstep %}
