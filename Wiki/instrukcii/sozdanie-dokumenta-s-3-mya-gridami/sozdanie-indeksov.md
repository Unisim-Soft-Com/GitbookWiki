# Создание индексов

{% stepper %}
{% step %}
### Шаг 1 — Открыть вкладку индексов

Выберите таблицу и перейдите на вкладку:

![](<../../.gitbook/assets/image (755)>)

Нажмите кнопку создания нового индекса:

![](<../../.gitbook/assets/image (756)>)

В поле имени индекса укажите название. В примере — `YVEINE_TMDB_INTAKE_LIST_A_IND`:

![](<../../.gitbook/assets/image (757)>)

Выберите таблицу, для которой создаётся индекс (кнопка с многоточием):

![](<../../.gitbook/assets/image (758)>)

Подтвердите выбор таблицы (OK):

![](<../../.gitbook/assets/image (759)>)

По умолчанию создается неуникальный индекс (Non-unique):

![](<../../.gitbook/assets/image (760)>)
{% endstep %}

{% step %}
### Шаг 2 — Выбрать колонки индекса

Перейдите на вкладку колонок:

![](<../../.gitbook/assets/image (761)>)

Выберите колонку(ы) двойным кликом или кнопкой добавления. В примере для первой таблицы выбирается колонка `NRDOC`:

![](<../../.gitbook/assets/image (762)>)

После выбора колонок нажмите OK:

![](<../../.gitbook/assets/image (763)>)
{% endstep %}

{% step %}
### Шаг 3 — Обновить панель деталей и проверить индекс

Чтобы увидеть созданный индекс в списке, нажмите «Refresh the detail panel»:

![](<../../.gitbook/assets/image (764)>)

В результате индекс появится в списке:

![](<../../.gitbook/assets/image (765)>)
{% endstep %}

{% step %}
### Шаг 4 — Повторить для второй таблицы (YVEINE\_TMDB\_INTAKE\_LIST\_B)

1. Откройте таблицу и вкладку индексов, нажмите создание нового индекса:

![](<../../.gitbook/assets/image (766)>)

2. Укажите имя индекса `YVEINE_TMDB_INTAKE_LIST_B_IND`:

![](<../../.gitbook/assets/image (767)>)

3. Выберите таблицу и подтвердите (OK):

![](<../../.gitbook/assets/image (768)>)

![](<../../.gitbook/assets/image (769)>)

4. На вкладке колонок выберите `NRDOC` и `NRDOC1`, затем OK:

![](<../../.gitbook/assets/image (770)>)

![](<../../.gitbook/assets/image (771)>)

5. Обновите панель деталей, чтобы увидеть индекс:

![](<../../.gitbook/assets/image (772)>)

Результат — добавлен индекс по колонкам `NRDOC` и `NRDOC1`:

![](<../../.gitbook/assets/image (773)>)
{% endstep %}

{% step %}
### Шаг 5 — Повторить для третьей таблицы (YVEINE\_TMDB\_INTAKE\_LIST\_C)

1. Откройте таблицу, вкладку индексов и создайте новый индекс:

![](<../../.gitbook/assets/image (774)>)

2. Укажите имя индекса `YVEINE_TMDB_INTAKE_LIST_C_IND`:

![](<../../.gitbook/assets/image (775)>)

3. Выберите таблицу и подтвердите (OK):

![](<../../.gitbook/assets/image (776)>)

![](<../../.gitbook/assets/image (777)>)

4. На вкладке колонок выберите `NRDOC`, `NRDOC1` и `NRDOC2`, затем OK:

![](<../../.gitbook/assets/image (778)>)

![](<../../.gitbook/assets/image (779)>)

5. Обновите панель деталей, чтобы увидеть индекс:

![](<../../.gitbook/assets/image (780)>)

Результат — индекс с колонками `NRDOC`, `NRDOC1` и `NRDOC2`:

![](<../../.gitbook/assets/image (781)>)
{% endstep %}

{% step %}
### Шаг 6 — Сохранение изменений (фиксация транзакции)

Для сохранения изменений в текущей транзакции нажмите кнопку Commit / сохранить:

![](<../../.gitbook/assets/image (782)>)

После нажатия кнопки изменения будут сохранены в транзакции:

![](<../../.gitbook/assets/image (783)>)
{% endstep %}
{% endstepper %}
