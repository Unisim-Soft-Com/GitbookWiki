### 4. Редактируем свойство (SQL) действия

Выделяем свойство (SQL) у скопированного Action и открываем редактирование (Edit property или двойной клик).

![](<../.gitbook/assets/image (352)>)

![](<../.gitbook/assets/image (353)>)

В поле редактирования указываем пакет Un$vp$util и через точку (!) процедуру alt\_seq, передавая в скобках номер документа через двоеточие (!): (:nrdoc,'10')

![](<../.gitbook/assets/image (354)>)

Подтверждаем OK в конфигураторе.
{% endstep %}

{% step %}
### 5. Настраиваем автовыполнение Action при сохранении документа

Находим свойства EAutoGFCOrder и EAutoGFCRun для нужного документа. Включаем Multiselect, нажав соответствующую кнопку.

![](<../.gitbook/assets/image (355)>)

Копируем два свойства для автовыполнения действия (Action) (через кнопку вставить или Ctrl+C):

![](<../.gitbook/assets/image (356)>)

И вставляем их (Ctrl+V или кнопкой вставить):

![](<../.gitbook/assets/image (357)>)

Примечание: в EAutoGFCOrder указывается ID действия, которое должно выполниться при сохранении документа. EAutoGFCRun включает автовыполнение действий при сохранении документа.

![](<../.gitbook/assets/image (358)>)
