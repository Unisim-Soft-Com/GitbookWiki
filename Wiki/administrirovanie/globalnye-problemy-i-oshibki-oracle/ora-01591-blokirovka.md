# ORA-01591: блокировка

SQL-запрос, при котором возникла ошибка:

```sql
SELECT VMDB_DOCS.* FROM VMDB_DOCS
WHERE DATAMANUAL BETWEEN '01.01.2016' AND '30.09.2016'
ORDER BY COD ASC
```

Сообщение об ошибке:

ORA-01591: блокировка, удерживаемая распред.транзакцией 28.19.482515, находящейся в неопр. сост

Проверил — нет связи с POS-кассами.

Источник обсуждения:\
http://www.sql.ru/forum/848072/ora-01591-blokirovka-uderzhivaemaya-raspred-tranzakciey-xx-nahodyashheysya-v-neopr-sost

В качестве решения помогли следующие команды:

```sql
grant FORCE any TRANSACTION to thk;
```

и выполнение цикла для отката подготовленных распределённых транзакций:

```plsql
BEGIN
  FOR f IN (SELECT *
            FROM dba_2pc_pending
            WHERE state = 'prepared')
  LOOP
    execute immediate ('rollback FORCE '''||f.LOCAL_TRAN_ID||'''');
  END LOOP;
END;
```

Похоже, что проблема возникла в момент выключения компьютеров на фирме1, т.к. в это время шел обмен.

{% hint style="danger" %}
Ошибка ORA-01591

ORA-01591: lock held by in-doubt distributed transaction 6.58.10015

— блокировка, удерживаемая распределённой транзакцией 6.58.10015, находящейся в неопределённом состоянии.
{% endhint %}

## По документации

Причина: была попытка доступа к ресурсу, заблокированному "повисшей" распределённой транзакцией, находящейся в состоянии подготовки.

Действие: чтобы определить связь баз данных и состояние транзакции, сравните номер транзакции в сообщении со столбцом GLOBAL\_TRAN\_ID таблицы DBA\_2PC\_PENDING. Попытайтесь восстановить сетевое соединение для координатора и узла — если это невозможно временно, обратитесь к администратору базы данных узла точки завершения транзакции (если он известен), чтобы "протолкнуть" ожидающую транзакцию.

## Из практики

Причина: ошибка может указывать на возникновение «смертельных объятий» — зацикливание процессов друг на друге. Может возникнуть при попытке удаления из мастер-группы/дест-сайта, если одна из БД других сайтов остановлена.

Действие: запустите базы данных всех сайтов и в состоянии мастер-группы NORMAL повторите операцию.
