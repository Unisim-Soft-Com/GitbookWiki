# Инструкция по выполнению апгрейда базы данных

{% hint style="info" %}
Минимальная совместимая версия ПО: 4.1.3.050
{% endhint %}

{% stepper %}
{% step %}
### Скопировать и распаковать свежую версию программы (Good)
{% endstep %}

{% step %}
### Запустить программу uniVersions.exe
{% endstep %}

{% step %}
### Обязательно сделать архив базы данных (или хотя бы сохранить структуру в файл)

**(Важно)**
{% endstep %}

{% step %}
### Подключиться к нужной схеме («Рабочая схема» в верхней части окна программы)
{% endstep %}

{% step %}
### Открыть страницу «Апгрейд БД по версиям» (вкладка «Upgrade»)
{% endstep %}

{% step %}
### Нажать кнопку «Загрузить»

(слева должен появиться список скриптов голубого цвета)
{% endstep %}

{% step %}
### Нажать кнопку «Какая версия?»

(в поле «С версии» должен появиться номер очередной версии)
{% endstep %}

{% step %}
### Галка «Только указанная схема» должна быть включена, если апгрейд выполняется на офисном сервере, и выключена – если на сервере клиента
{% endstep %}

{% step %}
### Нажать кнопку «Сформировать скрипт»

(должна открыться страница со сформированным скриптом)
{% endstep %}

{% step %}
### Включить галку «Пропускать ошибки»
{% endstep %}

{% step %}
### Нажать кнопку «Выполнить скрипт»

(на все последующие вопросы ответить утвердительно)
{% endstep %}

{% step %}
### Открыть страницу «Сравнение схем» (вкладка «Сравнение»)
{% endstep %}

{% step %}
### Утопить кнопку с желтой лейкой «Фильтр обрабатываемых объектов»
{% endstep %}

{% step %}
### На панели фильтра нажать кнопку «Все включить» и очистить поле «Имя сод.»

(для очистки этого поля можно нажать мышкой на надпись слева от него)
{% endstep %}

{% step %}
### В левой панели нажать кнопку «Загрузить с сервера…», ввести имя un4public, «Тип подключения» выбрать «Конкретная схема» и загрузить структуру схемы un4public
{% endstep %}

{% step %}
### В правой панели нажать стрелку справа от кнопки «Загрузить из файла...» и в выпадающем списке выбрать un4public
{% endstep %}

{% step %}
### Нажать кнопку «Скрипт на все различия (справа налево)»

(должна открыться страница со сформированным скриптом)
{% endstep %}

{% step %}
### Нажать кнопку «Выполнить скрипт»

(на все последующие вопросы ответить утвердительно)
{% endstep %}

{% step %}
### Открыть страницу «Сравнение схем» (вкладка «Сравнение»)
{% endstep %}

{% step %}
### В правой панели нажать кнопку «Очистить» и очистить панель от данных
{% endstep %}

{% step %}
### В левой панели нажать кнопку «Загрузить с сервера…», ввести имя рабочей схемы, «Тип подключения» выбрать «Абстрактная схема» и загрузить структуру рабочей схемы
{% endstep %}

{% step %}
### В правой панели нажать стрелку справа от кнопки «Загрузить из файла...» и в выпадающем списке выбрать un4std
{% endstep %}

{% step %}
### Нажать кнопку «Скрипт на все различия (справа налево)»

(должна открыться страница со сформированным скриптом)
{% endstep %}

{% step %}
### Нажать кнопку «Выполнить скрипт»

(на все последующие вопросы ответить утвердительно)
{% endstep %}

{% step %}
### Открыть страницу «Экспорт/импорт схемы» (вкладка «DataPump»)
{% endstep %}

{% step %}
### В поле «Новая схема» ввести имя рабочей схемы
{% endstep %}

{% step %}
### В рамке «После импорта схемы:» нажать кнопки «Сбор статистики» и «Скомпилировать»
{% endstep %}

{% step %}
### Закрыть программу uniVersions.exe
{% endstep %}
{% endstepper %}
