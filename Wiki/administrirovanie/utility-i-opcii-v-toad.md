# Утилиты и опции в toad

{% stepper %}
{% step %}
### Открыть восстановление документов

В главном меню программы выбрать File → Recover Documents...

![Recover Documents menu](<../.gitbook/assets/image (307)>)
{% endstep %}

{% step %}
### Окно "Recover documents"

При выборе пункта меню «Recover Documents» откроется окно восстановления (такое же окно появляется, если предыдущая работа в Toad была прервана с ошибкой).

![Recover Documents window](<../.gitbook/assets/image (308)>)
{% endstep %}

{% step %}
### Выбрать документы для восстановления

В окне «Recover documents» выделите документы (с зажатой клавишей Shift), которые нужно восстановить.
{% endstep %}

{% step %}
### Требование для восстановления

Для восстановления документов должно быть работающее подключение к соответствующим схемам.
{% endstep %}
{% endstepper %}
