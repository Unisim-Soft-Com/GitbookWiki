# Установка Toad

## Установка Toad

Установка программного обеспечения Toad производится на стенде виртуальной машины Oracle VM VirtualBox версии 4.2.16 r86992 на операционной системе Windows Server 2003 (установка только программы Toad) и Windows Server 2003 SP2 (полная установка всех утилит). Подключение Toad осуществляется к базе данных Oracle Database 11g версии 11.2.0.1.

Для установки программного обеспечения Toad необходимо открыть папку Toad DBA Suite for Oracle 11.0 Commercial и дважды кликнуть по файлу Toad DBA Suite for Oracle 11.0 Commercial.

![](<../.gitbook/assets/image (258)>)

В результате откроется главное меню установки, где необходимо согласиться с условиями лицензионного соглашения.

![](<../.gitbook/assets/image (259)>)

После чего нажать Далее (Next).

![](<../.gitbook/assets/image (260)>)

Далее необходимо выбрать, какие утилиты устанавливать, а какие нет. Обратите внимание на указанные утилиты: Toad for Data Analyst Base Edition, Quest SQL Optimizer for Oracle, Benchmark Factory for Databases и Spotlight on Oracle. Поскольку при установке на Windows Server 2003 некоторые компоненты могут отсутствовать, Toad требует наличие .NET Framework 3.5 SP1 и Microsoft MSXML 4.20.9818.0.

Внизу окна установки расположен путь установки, который при желании можно изменить.

![](<../.gitbook/assets/image (261)>)

При переходе по ссылке можно скачать недостающие модули.

![](<../.gitbook/assets/image (262)>)

Или установить только Toad for Oracle, поставив соответствующую галочку, и нажать Install.

![](<../.gitbook/assets/image (263)>)

На прогресс-баре можно наблюдать процесс установки.

![](<../.gitbook/assets/image (264)>)

По окончании установки появится сообщение "Installation complete!" — нажмите Далее (Next), затем Finish.

![](<../.gitbook/assets/image (265)>)

![](<../.gitbook/assets/image (266)>)

На этом выборочная установка Toad for Oracle завершена.

![](<../.gitbook/assets/image (267)>)

![](<../.gitbook/assets/image (268)>)

## Полная установка

Полная установка производится на операционной системе Windows Server 2003 SP2, которая удовлетворяет всем требованиям программного обеспечения Toad. При полной установке у каждой утилиты отображается версия, статус установки и индивидуальный статус-бар, а также общий статус-бар.

![](<../.gitbook/assets/image (269)>)

![](<../.gitbook/assets/image (270)>)

После достижения всех статус-баров 100% появится сообщение "Installation completed!" — нажмите Далее (Next), затем Finish.

![](<../.gitbook/assets/image (271)>)

![](<../.gitbook/assets/image (272)>)

На этом полная установка завершена — на рабочем столе появятся ярлыки Toad for Oracle и её утилит.

![](<../.gitbook/assets/image (273)>)

## Процедура активации (лечения)

Независимо от типа установки, Toad необходимо активировать.

После запуска ярлыка "Toad for Oracle 11" с рабочего стола появится сообщение о необходимости активации лицензии.

![](<../.gitbook/assets/image (274)>)

Запустите файл keygen.exe — откроется окно Quest Keymaker.

![](<../.gitbook/assets/image (275)>)

![](<../.gitbook/assets/image (276)>)

Из списка выберите тип продукта "TOAD".

![](<../.gitbook/assets/image (277)>)

В поле "Site Message" введите "bs" и нажмите Generate для генерации ключа.

![](<../.gitbook/assets/image (278)>)

![](<../.gitbook/assets/image (279)>)

Скопируйте полученный код в поле "Key", введите "bs" в поле "Site message" в окне активации Toad и нажмите Apply.

![](<../.gitbook/assets/image (280)>)

После успешного применения вы увидите данные о регистрации.

![](<../.gitbook/assets/image (281)>)

***

## Запуск

Запуск Toad осуществляется через ярлык на рабочем столе.

![](<../.gitbook/assets/image (282)>)

При первом запуске может появиться сообщение об отсутствии модуля настройки SQL (опционально можно поставить галочку "не показывать снова"). Подтвердите и продолжите.

![](<../.gitbook/assets/image (283)>)

В следующем окне можно выбрать копирование предыдущих файлов пользователя или выполнение чистой установки — нажмите Далее (Next) для продолжения.

![](<../.gitbook/assets/image (284)>)

Далее выбирается визуальный стиль интерфейса (выпадающий стиль, однорядные вкладки, многорядные вкладки, древовидный стиль и т.д.). Также можно включить отображение иконок (Show icons) для некоторых стилей.

_Выпадающий стиль:_

![](<../.gitbook/assets/image (285)>)

_Однорядные вкладки:_

![](<../.gitbook/assets/image (286)>)

_Многорядные вкладки:_

![](<../.gitbook/assets/image (287)>)

_Древовидный стиль:_

![](<../.gitbook/assets/image (288)>)

Далее откроются окна общих настроек (параметры запуска, параметры выключения, визуальный стиль панели инструментов и док-панели), настройки Oracle (включая опции Commit после каждого оператора, выполнение запросов в потоке, сохранение паролей, использование DBA-вью и т.д.), выбор сессий и поведение при завершении соединения (Commit/Rollback/запрос при наличии изменений). После настройки всех опций нажмите Далее (Next) для продолжения.

![](<../.gitbook/assets/image (289)>)

Доступны пакеты диагностики — выберите при необходимости и нажмите Далее (Next).

![](<../.gitbook/assets/image (290)>)

После завершения настройки нажмите Finish.

![](<../.gitbook/assets/image (291)>)

В главном меню выберите базу данных, тип подключения и (опционально) цвет оформления.

![](<../.gitbook/assets/image (292)>)

В примере созданная база данных называется ORCL — заполните имя пользователя (например, SYS) и пароль. Нажатие Connect выполнит вход под указанным пользователем (DBA).

![](<../.gitbook/assets/image (293)>)

После успешного подключения вы увидите интерфейс и сможете работать с базой данных.

![](<../.gitbook/assets/image (294)>)

![](<../.gitbook/assets/image (295)>)
