# Настройка и запуск ORACLE

Сервер и клиент Oracle установлены на одной машине (Windows XP).

В этом случае могут возникнуть проблемы с запуском утилиты sqlplus. Также запуск сервера Oracle, а именно startup базы, может выдавать ошибки. Необходимо правильно указать переменные окружения.

{% hint style="info" %}
В переменной PATH на первом месте должен быть путь к клиенту, например:
{% endhint %}

```
C:\oracle\product\10.2.0\client_1\bin;
```

{% hint style="warning" %}
Переменная ORACLE\_HOME должна быть пустой, иначе запускается только клиент или только сервер.
{% endhint %}
