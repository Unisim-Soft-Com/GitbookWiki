# Архивирование (Backup) удаленных документов

1. В параметрах конфигуратора включить опцию в секции `docs`:

```
Backup=true
```

2. Создать отдельную схему для логирования. Имя схемы должно содержать имя текущей схемы и оканчиваться на `_BK` (пример: `TAGAER_BK`).
3. Создать синонимы на основной схеме, которые ссылаются на объекты схемы `TAGAER_BK` (на `tmdb_docs` и на пакеты).
4. Данные из таблиц удаленных документов попадают в соответствующие таблицы схемы `TAGAER_BK`.\
   Если каких-то таблиц не хватает — они динамически создаются.
5. Пакеты, используемые для копирования, восстановления документов и создания недостающих объектов (таблиц) на схеме `_BK`:
   * `UN4DOC_BACKUP`
   * `Un4doc_Backup_Exec`

{% hint style="info" %}
Объекты базы данных для схемы `_BK` находятся в SVN: UNA\utils\backup\\
{% endhint %}
