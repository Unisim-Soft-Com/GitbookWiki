# Импорт из DBF

Для импорта из \*.dbf можно использовать утилиту Toad — в меню выбрать Database → Import → Import Table Data.

Далее необходимо выбрать таблицу, в которую будут импортированы данные, выбрать тип файла и указать соответствие столбцов источника и приемника (Destination - Source).

Настройка импорта из dbf в UNA.

{% stepper %}
{% step %}
### 1. Создать узел и добавить свойства в конфигураторе

Добавьте узел (или используйте уже существующий) и задайте свойства:

* **file\_name** – имя dbf-файла (с учетом регистра)
* **mat\_directory** – имя директории (ссылка на каталог сервера, где будет храниться dbf-файл)

Например: узел Lab (лаборатория)

![](<../../.gitbook/assets/image (220)>)
{% endstep %}

{% step %}
### 2. Создать папку на сервере

Создайте папку, например: \имя сервера\lab\_dbf
{% endstep %}

{% step %}
### 3. В Toad создать директорию

Пример:

create or replace directory LAB\_DBF as '/var/un4/lab\_dbf';
{% endstep %}

{% step %}
### 4. Дать права на директорию

В Toad под пользователем SYS дать grant на директорию:

Пример:

grant read, write on directory LAB\_DBF to схема;
{% endstep %}

{% step %}
### 5. Добавить экшен "Загрузить из dbf" в документ или форму

Добавьте соответствующий экшен в нужный документ/форму в приложении.
{% endstep %}

{% step %}
### 6. Отладка: ошибка «идентификатор нулевой длины не верен»

{% hint style="warning" %}
Если при выполнении экшена "Загрузить из dbf" программа выдает ошибку «идентификатор нулевой длины не верен», проверьте тип dbf — скорее всего стоит vfp3.
{% endhint %}

Тип структуры можно проверить через утилиту Total Commander (F3 — открыть файл, F6 — структура файла).

![](<../../.gitbook/assets/image (221)>)
{% endstep %}

{% step %}
### 7. Изменение типа структуры DBF

Чтобы изменить тип структуры БД, скачайте редактор (например Sdbf 4.5):

* http://habrahabr.ru/sandbox/73266/
* Sdbf 4.5.zip: https://yadi.sk/d/sqNrclCW3XDNTe

Запустите Sdbf 4.5: Файл → Открыть → выбрать dbf-файл. Далее меню Таблица → Изменить структуру → в поле Тип файла выбрать xBaseIII и сохранить.

Загрузите изменённый файл в папку на сервере.
{% endstep %}

{% step %}
### 8. Пример экшена "Загрузить из dbf"

В начале пакета добавить переменные:

{% code title="Пример PL/SQL" %}
```sql
-- в начале пакета добавить переменные
v_directory varchar2(100) := pkg_adm_util.get_adm_text('lab_directory','','LAB');
v_file_name varchar2(100) :=pkg_adm_util.get_adm_text ('file_name', '', 'LAB');
--
procedure fill_from_dbf
is
begin
 --чистим временную таблицу (У нее должна быть такая же структура, как у файла dbf)
 delete from ztmp_texgot_dbf;
 -- процедура загрузки из файла во временную таблицу
 un$dbf.load_table(v_directory,v_file_name,'ztmp_texgot_dbf');
/*... далее используем временную таблицу ...*/
end;
```
