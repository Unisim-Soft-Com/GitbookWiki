# Некорректные остатки

Проблема: в универсальном отчете появился некорректный остаток на счете :cont.

Если на вьюхах vmdb\_cmr, vmdb\_cmi нет проводок, которые дают некорректные остатки, нужно проверить их в таблице **tmdb\_cm**.

{% stepper %}
{% step %}
### Проверка в tmdb\_cm

Выполните поиск проводок по диапазону дат и по счету (ct или dt):

{% code title="Пример запроса" %}
```sql
select *
from tmdb_cm
where data between :datastart and :dataend
and (ct=:cont or dt=:cont)
```
{% endcode %}

Такие проводки могут возникнуть, если удаление было выполнено из tmdb\_cm (в жабе).
{% endstep %}

{% step %}
### Решение — удалить проводки проблемного документа через УНУ

Сначала посмотрите строчки по номеру документа, затем удалите их из TMDB\_CM:

{% code title="Проверка строк документа" %}
```sql
select *
from tmdb_cm
where nrdoc = :nrdoc;
```
{% endcode %}

{% code title="Удаление строк документа" %}
```sql
delete from tmdb_cm
where nrdoc = :nrdoc;
```
{% endcode %}
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Перед удалением убедитесь, что вы правильно определили номер документа (:nrdoc) и что удаление не нарушит целостность данных. Рекомендуется сделать резервную копию или выполнить операцию в тестовой среде.
{% endhint %}
