# Процедура set\_conts\_list

В пакете pkg\_pdc\_util описаны две перегрузки процедуры set\_conts\_list — с параметром и без.

Если вызывать процедуру без параметров, то она возвращает список всех счетов. Например:

{% code title="Пример вызова (все счета)" %}
```plsql
pkg_pdc_util.set_conts_list();
```
{% endcode %}

Если нужен список конкретных счетов или их группа, можно передать значения в процедуру, например:

{% code title="Пример вызова (ограниченный список)" %}
```plsql
pkg_pdc_util.set_conts_list('2 3 5421 9111');
```
{% endcode %}

* Название свойства: PSQL\
  Тип: Memo\
  Описание: текст предварительного SQL (Prepare SQL)\

* Название свойства: SagiEditQuery\
  Тип: Boolean\

Настройка в клиенте для объекта, где используется такой справочник

{% stepper %}
{% step %}
### Открыть настройки объекта

Выберите объект и откройте настройки сочетанием клавиш Alt+D, затем выберите вкладку SQL.
{% endstep %}

{% step %}
### Указать тип списка

Нажмите на иконку "блокнотик" (на изображении) и в появившемся поле пропишите название справочника: TIPNODE=PDC

![](<../../.gitbook/assets/image (192)>)
{% endstep %}

{% step %}
### Войти в List setup и задать поля

Еще раз нажмите ту же кнопку, вернитесь в настройки и откройте List setup. Пропишите соответствующие поля:

* cont — поле, которое выбираем
* ct — поле, в которое происходит заполнение (insert)

Поставьте галочку Save on exit и сохраните изменения (кнопка Ок).

![](<../../.gitbook/assets/image (193)>)
{% endstep %}
{% endstepper %}

После выполненных действий в поле "Счет Кт" будет выпадать справочник со всеми счетами.

Ограничение справочника

{% hint style="info" %}
Чтобы ограничить набор отображаемых счетов, в настройках объекта "Счет Кт" в Prepare SQL пропишите вызов процедуры с нужными параметрами.
{% endhint %}

Пример Prepare SQL с ограничением:

{% code title="Пример Prepare SQL (ограничение)" %}
```plsql
begin
  pkg_pdc_util.set_conts_list('3 2411');
end;
```
{% endcode %}
