### Установить шрифт в печатной форме

В печатной форме для ячейки установите нужный шрифт, например:

EAN-13 HalfHeight
{% endstep %}

{% step %}
### Преобразовать значение в запросе

В запросе преобразуйте значение, используя функцию `un$bcod.MakeEAN13`. Пример:

{% code title="Пример" %}
```
un$bcod.MakeEAN13(nrdoc)
```
