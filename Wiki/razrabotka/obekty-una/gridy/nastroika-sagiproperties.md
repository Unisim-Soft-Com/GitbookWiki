# Настройка SagiProperties

![Минимальный набор настроек SagiProperties](<../../../.gitbook/assets/image (196)>)

Редактирование поля без F4 — в дизайне формы выставить в свойствах выбранного поля:

Other Field Properties: Input mode: **KeyBoard Mode = 2**

***

Добавление фильтров к Univers:

Пример: Attribute = T, Grouping = `COST\cod in (60086,60089,60088).`

***

Чтобы обратиться к дате в шапке формы/документа:

TO\_DATE(SYS\_CONTEXT('ENVUN4','V\_DATAB'))

***

Если в поле символ P и задан шрифт Wingdings 2 — на его месте появится галочка.

Настройка CheckMark:

* CheckMark = 1
* галка — ReadOnly
* опционально: шрифт Wingdings2, жирный, зелёный, размер 14

Двойной клик левой кнопкой мыши ставит в ячейку галку/указанную цифру/букву и т.п.

{% hint style="info" %}
Если нужно, чтобы в ячейке ставилась галка по двойному клику: используйте CheckMark = 1 и соответствующие свойства шрифта.
{% endhint %}

***

В формах с подчинённым гридом (когда FormUseDetail = true) необходимо убрать пробелы из условия where в Sagi Properties, чтобы работали параметры, которые берутся из верхнего грида.

Пример правильного фильтра:

```
ID_M=:ID_M AND ID_D1=:ID_D1
```

Пример неправильного фильтра:

```
ID_M = :ID_M AND ID_D1 = :ID_D1
```

{% hint style="warning" %}
В условии where не должно быть пробелов вокруг знака равенства и двоеточия, иначе параметры из верхнего грида не подставятся.
{% endhint %}

***

В документах и формах вычисляемые поля должны иметь тот же корень, что и поле с кодом.

Например:

* cod\_munc, clccod\_munct

Иначе значение поля в клиенте невозможно удалить — можно только заменить на другое.
