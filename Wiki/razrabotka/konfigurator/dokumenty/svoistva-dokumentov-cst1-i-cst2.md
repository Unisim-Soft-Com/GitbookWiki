# Свойства документов CST1 и CST2

Документы типа DLL с ID = 900 и DocName = CST1 или DocName = CST2 имеют свойство Design, позволяющее настраивать внешний вид документа в окне конструктора формы.

## CST1

Тип документа CST1 содержит 2 грида.

![](<../../../.gitbook/assets/image (3)>)

При нажатии на кнопку\
![Design button](<../../../.gitbook/assets/image (4)>)\
откроется окно изменения дизайна:

![](<../../../.gitbook/assets/image (5)>)

## CST2

Тип документа CST2 содержит 2 грида и шапку.

![](<../../../.gitbook/assets/image (6)>)

При нажатии на кнопку\
![Design button](<../../../.gitbook/assets/image (4)>)\
откроется окно изменения дизайна:

![](<../../../.gitbook/assets/image (7)>)

## Дочерние объекты

Дочерние объекты объектов типа Документы:

* объекты типа Action,
* объекты типа Totals,
* объекты типа PrintForms.

Узлы для этих объектов не могут иметь субузлов.

## Настройка SQL-запросов

SQL-запросы для документов DocName = CST1 и DocName = CST2 можно настроить в дизайне документа.

Выберите в дизайне объект osmCST1\_1 — для первого грида (или osmCST1\_2 — для второго) и запишите запросы в соответствующих свойствах этого объекта.
