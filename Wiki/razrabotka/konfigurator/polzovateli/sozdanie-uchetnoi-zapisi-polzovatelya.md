# Создание учетной записи пользователя

{% stepper %}
{% step %}
### Запуск конфигуратора UniConf

Запустите конфигуратор UniConf путем двойного щелчка по ярлыку UniConf на рабочем столе. Если ярлык отсутствует, откройте конфигуратор, используя путь: Мой компьютер -> Диск D -> Shares -> Good -> UniConf.
{% endstep %}

{% step %}
### Выбор категории Users

Установите курсор на категории Users.

![](<../../../.gitbook/assets/image (1054)>)
{% endstep %}

{% step %}
### Выбор группы пользователей

В нижнем блоке появится список групп пользователей. Выберите необходимую группу пользователей.

![](<../../../.gitbook/assets/image (1055)>)
{% endstep %}

{% step %}
### Открытие настроек (Options)

В меню выберите Options, используя путь Service -> Options…

![](<../../../.gitbook/assets/image (1056)>)

Или нажмите кнопку Настройки на панели инструментов.

![](<../../../.gitbook/assets/image (1057)>)
{% endstep %}

{% step %}
### Отключение проверки изменений свойств

Поставьте галочку напротив Don't check property changes и нажмите кнопку ОК.

![](<../../../.gitbook/assets/image (1058)>)
{% endstep %}

{% step %}
### Экспорт свойств учетной записи в буфер

Установите курсор на одной из учетных записей пользователя и щелкните правой кнопкой мыши. В появившемся меню выберите Data -> Export -> Node

![](<../../../.gitbook/assets/image (1059)>)

Или нажмите на кнопку с изображением листа -> Export -> Node.

![](<../../../.gitbook/assets/image (1060)>)
{% endstep %}

{% step %}
### Подтверждение копирования узла в буфер

Должно появиться сообщение Copy nodes to clipboard…. Нажмите кнопку ОК.

![](<../../../.gitbook/assets/image (1061)>)
{% endstep %}

{% step %}
### Выбор группы для создания нового пользователя

Установите курсор на группе (например, Ведущие специалисты).

{% hint style="info" %}
Каждой учетной записи пользователя должен быть присвоен уникальный код. В таблице Свойства в строке UserGroupList указаны идентификационные номера, которые могут быть присвоены пользователям в данной группе.

Если все номера уже присвоены учетным записям пользователей в группе и требуется новая учетная запись, можно добавить идентификационные номера путем двойного щелчка на UserGroupList и указания порядкового номера для новой учетной записи.
{% endhint %}

![](<../../../.gitbook/assets/image (1062)>)
{% endstep %}

{% step %}
### Открытие буфера

Откройте буфер, выбрав пункт меню Data -> Buffer либо нажав комбинацию Ctrl+B.

![](<../../../.gitbook/assets/image (1063)>)
{% endstep %}

{% step %}
### Редактирование созданной учетной записи в буфере — установка Caption и ID

Окно буфера открылось. Установите курсор на созданной учетной записи пользователя. Правой кнопкой мыши нажмите на него и выберите опцию Node properties.

В поле Caption укажите имя новой учетной записи пользователя.

Обычно используется формат: Первая буква имени + фамилия. Остальные поля автоматически поменяются после смены первого значения. Нажмите кнопку ОК.

В таблице Свойства дважды щелкните по строке ID. В появившемся окне в поле Value поменяйте ID на следующий порядковый номер и нажмите кнопку ОК.

![](<../../../.gitbook/assets/image (1064)>)
{% endstep %}

{% step %}
### Удаление строки Encoded (если требуется) и указание UserName

Установите курсор на строке Encoded и удалите ее, нажав на кнопку с изображением корзины.

![](<../../../.gitbook/assets/image (1065)>)

Установите курсор на строке UserName, дважды щелкните по ней и в появившемся окне укажите имя пользователя.
{% endstep %}

{% step %}
### Добавление свойства Password

Нажмите на кнопку Новое свойство.

![](<../../../.gitbook/assets/image (1066)>)

В появившемся окне в поле Name укажите Password и в поле Value — пароль новой учетной записи пользователя. Нажмите кнопку ОК.

![](<../../../.gitbook/assets/image (1067)>)
{% endstep %}

{% step %}
### Импорт нового узла из буфера в выбранную группу

Закройте окно буфера. Щелкните правой кнопкой мыши по той учетной записи пользователя, свойства которой экспортировали в буфер. В появившемся меню выберите Data -> Import -> New node

![](<../../../.gitbook/assets/image (1068)>)

Или нажмите на кнопку с изображением листа -> Import -> New node.

![](<../../../.gitbook/assets/image (1069)>)
{% endstep %}

{% step %}
### Ожидание и подтверждение вставки из буфера

Дождитесь, пока в сообщении Paste nodes from clipboard… кнопка Cancel заменится на кнопку ОК.

![](<../../../.gitbook/assets/image (1070)>)
{% endstep %}

{% step %}
### Скрытие пароля (преобразование в Encoded)

Чтобы пароль новой учетной записи не был доступен к просмотру, установите курсор на только что созданной учетной записи пользователя и щелкните правой кнопкой мыши. В появившемся меню выберите Execute SQL -> Hide User Password.

![](<../../../.gitbook/assets/image (1071)>)

Или нажмите на кнопку с изображением лампочки -> Hide User Password.

![](<../../../.gitbook/assets/image (1072)>)

Данная команда заменит свойство Password на свойство Encoded.
{% endstep %}

{% step %}
### Сохранение изменений

Нажмите на кнопку с изображением красной галочки на панели инструментов, чтобы подтвердить сохранение всех сделанных изменений.

![](<../../../.gitbook/assets/image (1073)>)
{% endstep %}
{% endstepper %}
