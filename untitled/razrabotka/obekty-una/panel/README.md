# Панель

Во время выполнения программы можно менять некоторые параметры. Имеют наивысший приоритет, но время действия настроек ограничено сеансом.

## Язык интерфейса

**Имя свойства:** Language\
**Тип:** String\
**Описание:** Язык интерфейса. Язык интерфейса задается либо цифрой (0, 1, 2), либо буквой (E, M, R). Язык окна регистрации задается только методом File. Если язык не задан ни одним из методов, система переводов выключается на весь сеанс работы.\
**Значение для примера:** Language

![](<../../../.gitbook/assets/image (199)>)

## Загрузка настроек, дизайнов, переводов и т.п.

### LogParams

**Тип:** Boolean\
**Описание:** Контроль настроек. Режим записи в текстовый файл всех считываемых настроек (до и после обработки и фильтрации).

![](<../../../.gitbook/assets/image (200)>)

### GridPropCacheLimit

**Тип:** Integer\
**Описание:** Размер кеша дизайнов. Максимальный размер кеша дизайнов в памяти. За единицу берется один тип документа, один узел дерева отчетов, одна форма или справочник.

![](<../../../.gitbook/assets/image (201)>)

### RepairGridDesign

**Тип:** Boolean\
**Описание:** Исправление ошибок. Режим автокоррекции загружаемых дизайнов (бывает нужен при работе с ORACLE 9i).

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=http%3A%2F%2Fwiki.bsoft.biz%2Fxwiki%2Fbin%2Fdownload%2F%25D0%25A0%25D0%25B0%25D0%25B7%25D1%2580%25D0%25B0%25D0%25B1%25D0%25BE%25D1%2582%25D0%25BA%25D0%25B0%2F%25D0%259F%25D0%25B0%25D0%25BD%25D0%25B5%25D0%25BB%25D1%258C%2FRepairGridDesign.png\&width=300\&dpr=4\&quality=100\&sign=ebbf1b9f\&sv=2)

### LangDontLoad

**Тип:** Boolean\
**Описание:** Не загружать переводы. Не пытаться загружать тексты переводов из ORACLE (для уменьшения траффика).

![](<../../../.gitbook/assets/image (202)>)

### LoadCaptionsSep

**Тип:** Boolean\
**Описание:** Заголовки отдельно. Режим раздельной загрузки переводов заголовков столбцов и дизайнов (для совместимости с переводами заголовков столбцов, сохраненными в предыдущих версиях SL).

![](<../../../.gitbook/assets/image (203)>)

***

## Ограничение прав пользователей

### DesignGroup

**Тип:** Integer\
**Описание:** Номер группы дизайнов (ненулевое значение позволяет пользователю иметь персональные дизайны, переводы, схемы отчетов и т.п.). Администратор может менять себе этот номер во время выполнения программы (через интерфейс меню).

![](<../../../.gitbook/assets/image (204)>)

***

## Панели инструментов

### TBIconStyle

**Тип:** Integer\
**Описание:** Расположение значков. Число от 0 до 3 означает положение значка относительно пункта главного меню:

* 0 - Значки не выводятся на экран (в меню - только надписи);
* 1 - Надписи не выводятся на экран (в меню - только значки);
* 2 - Значки выводятся на экран слева от соответствующих надписей;
* 3 - Значки выводятся на экран над соответствующими надписями.

![](<../../../.gitbook/assets/image (205)>)

### TBIconSize

**Тип:** Integer\
**Описание:** Размер значков. Число от 0 до 2 означает размер значков в главного меню:

* 0 - Мелкие значки;
* 1 - Средние значки;
* 2 - Крупные значки.

![](<../../../.gitbook/assets/image (206)>)

### TBPeriod

**Тип:** Boolean\
**Описание:** Панель периодов. Отображать на экране панель ввода периодов.

![](<../../../.gitbook/assets/image (207)>)

### TBWindowList

**Тип:** Boolean\
**Описание:** Панель открытых окон. Отображать на экране панель открытых окон.

![](<../../../.gitbook/assets/image (208)>)

## Настройка окна менеджера отчетов

### RepDataStart

**Тип:** String\
**Описание:** Дата начала периода просмотра данных в отчетах. Допускается SQL-выражение. Если значение параметра отсутствует, вместо него используется значение параметра PeriodStart.

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=http%3A%2F%2Fwiki.bsoft.biz%2Fxwiki%2Fbin%2Fdownload%2F%25D0%25A0%25D0%25B0%25D0%25B7%25D1%2580%25D0%25B0%25D0%25B1%25D0%25BE%25D1%2582%25D0%25BA%25D0%25B0%2F%25D0%259F%25D0%25B0%25D0%25BD%25D0%25B5%25D0%25BB%25D1%258C%2F%25D0%2594%25D0%25B0%25D1%2582%25D0%25B0%2520%25D0%25BD%25D0%25B0%25D1%2587%25D0%25B0%25D0%25BB%25D0%25B0%2520%2528%25D0%25BE%25D1%2582%25D1%2587%25D0%25B5%25D1%2582%2529.png\&width=300\&dpr=4\&quality=100\&sign=f98e8deb\&sv=2)

### RepDataEnd

**Тип:** String\
**Описание:** Дата окончания периода просмотра данных в отчетах. Допускается SQL-выражение. Если значение параметра отсутствует, вместо него используется значение параметра PeriodEnd.

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=http%3A%2F%2Fwiki.bsoft.biz%2Fxwiki%2Fbin%2Fdownload%2F%25D0%25A0%25D0%25B0%25D0%25B7%25D1%2580%25D0%25B0%25D0%25B1%25D0%25BE%25D1%2582%25D0%25BA%25D0%25B0%2F%25D0%259F%25D0%25B0%25D0%25BD%25D0%25B5%25D0%25BB%25D1%258C%2F%25D0%2594%25D0%25B0%25D1%2582%25D0%25B0%2520%25D0%25BE%25D0%25BA%25D0%25BE%25D0%25BD%25D1%2587%25D0%25B0%25D0%25BD%25D0%25B8%25D1%258F%2520%2528%25D0%25BE%25D1%2582%25D1%2587%25D0%25B5%25D1%2582%2529.png\&width=300\&dpr=4\&quality=100\&sign=a0a7f0bb\&sv=2)

### RepTestRecordCount

**Тип:** Boolean\
**Описание:** Проверять к-во записей. Режим проверки количества записей в наборе данных отчета (для F1Reports): при очень большом количестве записей выдается предупреждающее сообщение, имеется возможность отменить построение отчета или вручную ограничить количество выводимых записей. Предельное количество записей для отчетов Master/Detail - 1000, только Master - 10000.

![](<../../../.gitbook/assets/image (211)>)

### RepDeleteTempTables

**Тип:** Boolean\
**Описание:** Удалять врем. таблицы. Режим удаления временных таблиц ORACLE после построения отчета (можно выключить).

![](<../../../.gitbook/assets/image (212)>)

## Разные настройки

### GridDisableNumberSearch

**Тип:** Boolean\
**Описание:** Запрет числового поиска. Режим текстового поиска даже в числовых полях грида (вместо числового поиска).

![](<../../../.gitbook/assets/image (213)>)

### UseSmartTab

**Тип:** Boolean\
**Описание:** "Умный" . Режим интеллектуального поведения клавиши : переход от поля к полю по всему активному окну.

![](<../../../.gitbook/assets/image (214)>)

### UseSmartEnter

**Тип:** Boolean\
**Описание:** "Умный" . Режим интеллектуального поведения клавиши на дополнительной (цифровой) клавиатуре: при редактировании таблиц - переход к следующему полю или (из последнего столбца) завершение редактирования и вставка новой записи.

![](<../../../.gitbook/assets/image (215)>)

### UseSpeedSearch

**Тип:** Boolean\
**Описание:** Быстрый поиск в справ.. Режим быстрого поиска в выпадающих справочниках.

![](<../../../.gitbook/assets/image (216)>)
