# Настройка документа для ввода данных сканером штрих-кодов

21.04.2006

## Настройка документа для ввода данных сканером штрих-кодов

{% stepper %}
{% step %}
### Включить UseSmartEnter

Правый \<Enter> будет работать как \<Tab>, а в конце строки сохранять ее и вставлять следующую (Insert).\
(Свойство включать на учетке пользователя.)
{% endstep %}

{% step %}
### Поле со штрихкодом — выпадающий справочник

Настроить как выпадающий справочник, включив опции:

* "Using speed search"
* "Search text value"
* "Search whole text"
{% endstep %}

{% step %}
### Связка с полем, содержащим код Univers

Добавить свойство: Origin=\[code\_field\_name]\
(например, для DTSC: Origin=DTSC)
{% endstep %}

{% step %}
### Автоматический фокус после Insert

Чтобы после Insert выбиралось сразу это поле, добавить свойство: StartField=1
{% endstep %}

{% step %}
### Справочник как произвольный SQL-запрос

Если справочник настроен как произвольный SQL-запрос, обязательно указать:

* List Fields
* Result Fields

(2 поля через запятую: поле кода Univers и поле штрих-кода)
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Первый раз надо нажать Insert, а дальше — только правый \<Enter>.
{% endhint %}
