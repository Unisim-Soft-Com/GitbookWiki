# Display Format Edit mask

Формат ячеек итогов наследуется от формата столбцов грида. Также формат итогов можно задать явно:

Примеры форматов:

* ZILE — только целая часть:

```
ZILE="%.0F"
```

* ORE — в дробной части 1 знак:

```
ORE="%.1F"
```

* ORE\_NOCI — в дробной части 3 знака:

```
ORE_NOCI="%.3F"
```

Формат отображения даты и времени:

```
dd.mm.yyyy hh:nn:ss
```

Формат отображения чисел:

```
\### ### ##0.00
```

Маска ввода даты и времени:

```
99.99.9999 99:99:99
```

Маска ввода для чисел:

```
99.99
```
