# Импорт CSV файла

## Описание процедур

Стандартные процедуры импорта позволяют импортировать объект CLOB, который может быть загружен в документ — в таблицу `VMDB_DOCS_OLE`.

Для этого нужно вызвать процедуру со следующими параметрами.

{% stepper %}
{% step %}
### Вариант 1 — по идентификаторам документа

```sql
procedure clob_to_table
(
  p_nrdoc   number,
  p_nrdoc1  number,
  p_struct_id number,
  p_do_delete boolean := true,
  p_separator varchar2 := chr(9)
)
```

где `p_nrdoc` и `p_nrdoc1` — это идентификаторы строки с объектом CLOB в таблице `VMDB_DOCS_OLE`.
{% endstep %}

{% step %}
### Вариант 2 — напрямую передать CLOB

```sql
procedure clob_to_table
(
  p_clob     clob,
  p_struct_id number,
  p_do_delete boolean := true,
  p_separator varchar2 := chr(9)
)
```

в этом варианте вы передаёте сам объект `p_clob`.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
При вызове процедуры необходимо указать значение параметра `p_struct_id` — это идентификатор описания структуры временной таблицы, которую нужно описать в таблицах `TMS_LOAD_INFO` и `TMS_LOAD_STRUCT`.
{% endhint %}

## Описание таблиц

Необходимо создать временную таблицу с определённой структурой (ON COMMIT PRESERVE ROWS).

В таблице `TMS_LOAD_INFO` есть параметры:

* `PACK_SEPARATORS` — если значение = 1, то при импорте файла будут удалены повторяющиеся разделители.
* `UNQUOTE_VALUES` — если значение = 1, то при импорте будут удалены кавычки справа и слева в полях типа `S` (string). Примечание: работает некорректно.

Обязательные для заполнения поля в `TMS_LOAD_INFO`:

* `ID` — уникальный идентификатор.
* `TABLENAME` — название временной таблицы.

В таблице `TMS_LOAD_STRUCT` необходимо описать каждое поле временной таблицы для текущего `ID`. Указываются:

* `COL` — номер по порядку (порядок полей должен совпадать с порядком в .csv файле),
* `COLUMNNAME` — название поля,
* `TYPE` — тип поля,
* `PREC` — размер поля.

Остальные параметры в `TMS_LOAD_STRUCT` являются необязательными для заполнения.
