# Загрузка курсов валют

Пакет Valutaloader позволяет загружать курсы с сайта банков в двух форматах:

* xml — функция `load`
* csv — функция `load_from_csv`

Структура xml и csv файлов может отличаться от обрабатываемой в процедуре. Нужно настроить процедуру под конкретную структуру файла.

Обе функции загружают курсы за один день. В некоторых случаях банк может вернуть курс за предыдущую дату — тогда функция добавит данные в ту дату, на которую была вызвана.

Для загрузки за период в пакете есть функция `LOADING_PERIOD`. Параметр `tip` этой функции определяет, каким методом будет идти загрузка.

Для загрузки курсов валют необходимо дать схеме права на загрузку с определенного веб-ресурса (ACL — права доступа для почты и веб-запросов). Пример последовательности действий для настройки ACL:

{% stepper %}
{% step %}
### Создание ACL

Создаем ACL и задаем адрес сервера/порт (пример: localhost:465).

{% code title="Создать ACL" %}
```sql
EXECUTE DBMS_NETWORK_ACL_ADMIN.CREATE_ACL('acl_for_get_curs.xml', 'ACL for getting curs', 'DEV', TRUE, 'connect');
```
{% endcode %}
{% endstep %}

{% step %}
### Добавление привилегий в существующий ACL

Добавляем еще привилегии в существующий ACL (например, чтобы дать прав нескольким схемам).

{% code title="Добавить привилегию" %}
```sql
EXECUTE DBMS_NETWORK_ACL_ADMIN.ADD_PRIVILEGE('acl_for_get_curs.xml', 'BOX', TRUE, 'connect');
```
{% endcode %}
{% endstep %}

{% step %}
### Привязка ACL к хосту(ам)

Допускается добавление нескольких хостов в один ACL. Пример назначения для домена:

{% code title="Назначить ACL хосту" %}
```sql
EXECUTE DBMS_NETWORK_ACL_ADMIN.ASSIGN_ACL('acl_for_get_curs.xml', '*.cbpmr.net');
```
{% endcode %}
{% endstep %}

{% step %}
### Проверка созданных ACL

Проверяем, что только что созданный список появился в базе:

{% code title="Просмотр ACL" %}
```sql
SELECT host, lower_port, upper_port, acl FROM dba_network_acls;
```
{% endcode %}
{% endstep %}

{% step %}
### Просмотр пользователей в ACL

Просматриваем список пользователей/приватов, добавленных в ACL:

{% code title="Просмотр привилегий ACL" %}
```sql
SELECT acl, principal, privilege, is_grant, invert FROM dba_network_acl_privileges;
```
{% endcode %}
{% endstep %}
{% endstepper %}

Если нужно, настраивайте процедуру загрузки под конкретную структуру XML/CSV файлов перед использованием функций `load` или `load_from_csv`.
