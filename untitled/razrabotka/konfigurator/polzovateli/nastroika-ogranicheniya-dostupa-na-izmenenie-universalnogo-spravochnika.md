# Настройка ограничения доступа на изменение универсального справочника

Можно заблокировать от изменений отдельные разделы справочника и дать отдельным пользователям права на внесение изменений в отдельные разделы, в том числе заблокированные.

{% stepper %}
{% step %}
### Выполнить апгрейд базы до версии 370

Выполните обновление базы данных до версии 370.
{% endstep %}

{% step %}
### Заполнить таблицу TMS\_UNIVLOCK блокирующими записями

Для каждого блокируемого раздела укажите фамилию ответственного, добавив записи вида:

{% code title="SQL" %}
```sql
INSERT INTO TMS_UNIVLOCK (TIP,GR1,PERSON) VALUES ('O','E','Vasea')
```
{% endcode %}
{% endstep %}

{% step %}
### Внести разрешающие записи в InitSQL для отдельных пользователей

Отдельным пользователям добавьте в InitSQL записи вида:

{% code title="SQL" %}
```sql
INSERT INTO VUNIVUNLOCK (TIP,GR1) VALUES ('O','E')
```
{% endcode %}
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Примечание:

* Если не указан GR1 — подразумевается любой GR1 при указанном TIP.
* Если не указаны ни TIP, ни GR1 — подразумевается весь справочник.
{% endhint %}
