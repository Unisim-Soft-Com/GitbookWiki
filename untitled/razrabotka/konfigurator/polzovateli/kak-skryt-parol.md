# Как скрыть пароль

Для скрытия пароля выполните одно из следующих действий:

* В контекстном меню узла Execute SQL выбрать Hide User Password после ввода свойства Password.

![](<../../../.gitbook/assets/image (1074)>)

* Или нажать на кнопку с изображением жёлтой лампочки на тулбаре над деревом и в появившемся меню выбрать Hide User Password.

![](<../../../.gitbook/assets/image (1075)>)

Эта команда заменит свойство Password на свойство Encoded, чтобы никто не смог прочитать пароль.

![](<../../../.gitbook/assets/image (1076)>)
