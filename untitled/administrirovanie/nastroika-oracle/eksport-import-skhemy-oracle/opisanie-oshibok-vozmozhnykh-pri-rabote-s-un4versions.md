# Описание ошибок, возможных при работе с un4Versions

Описание:

Ошибка может возникнуть при попытке выполнить экспорт или импорт схемы на странице "Экспорт/импорт схемы".\
Вместо DIR\_NAME в ошибке будет присутствовать имя выбранной директории.\
Если имя директории в поле "Oracle Directory" не указано, будет использована стандартная директория DATA\_PUMP\_DIR.

Возможные причины и методы устранения:

{% stepper %}
{% step %}
### Имя директории введено вручную, но данной директории не существует на сервере

* Выберите одну из существующих на сервере директорий при помощи кнопки выбора рядом с полем "Oracle Directory".
* Или введите вручную имя существующей директории.
{% endstep %}

{% step %}
### Поле "Oracle Directory" не заполнено и на сервере не существует стандартной директории DATA\_PUMP\_DIR

* Воспользуйтесь одной из существующих директорий, выбрав одну из них из списка.
{% endstep %}

{% step %}
### На сервере не создано ни одной директории

* Создайте Oracle Directory и выдайте права на работу с ней нужным пользователям. Для этого нужно выполнить несколько скриптов от имени пользователя SYS.

Создание директории:

{% code title="Создание директории" %}
```sql
create directory DIR_NAME as 'PATH_NAME';
```
{% endcode %}

Вместо DIR\_NAME можно задать любое имя для новой директории.\
Вместо PATH\_NAME необходимо указать путь к папке файловой системы сервера, к которой есть доступ на чтение/запись у учётной записи ОС, от имени которой запускается процесс oracle.exe (обычно под Windows это SYSTEM).

Выдача прав:

{% code title="Выдача прав" %}
```sql
grant all on directory DIR_NAME to imp_full_database;

grant all on directory DIR_NAME to exp_full_database;
```
{% endcode %}

При необходимости:

{% code title="Выдача прав конкретному пользователю" %}
```sql
grant all on directory DIR_NAME to USERNAME;
```
{% endcode %}

* Вместо DIR\_NAME — имя созданной директории.
* Вместо USERNAME — имя пользователя, от имени которого необходимо выполнить импорт или экспорт (если это не SYS).
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Если при выполнении скриптов возникли какие‑либо проблемы — обратитесь к документации или к администратору (DBA).
{% endhint %}
