# Использование контекстов приложения

Имя контекста — `UN$FM`. Пакет, с которым он связан в данном случае — `UN4PUBLIC.UN$FM`.

SQL-операция создания контекста и привязки к пакету:

```sql
create or replace context UN$FM using UN$FM;
```

Итак, теперь созданы контекст с именем `UN$FM` и пакет с процедурами для его установки.

{% hint style="info" %}
Важно: поскольку контекст связан с процедурами пакета `UN$FM`, этот пакет является единственным средством установки значений контекста.
{% endhint %}

Если, например, попытаться установить в этом контексте значение напрямую с помощью `dbms_session.set_context`, то выполнить это нельзя — операция будет прервана. Пример:

```plsql
BEGIN
  dbms_session.set_context('un$fm', 'used', '1');
END;
```

Результат выполнения:

```
ORA-01031: привилегий недостаточно
ORA-06512: на  "SYS.DBMS_SESSION", line 101
ORA-06512: на  line 2
```

Это показывает, что `dbms_session.set_context` не может установить значения для контекста `UN$FM` напрямую — только через процедуры пакета `UN$FM`.

Значения контекста можно установить только через процедуры пакета. В этом случае гарантируется, что, если значение и существует, то оно проверено и установлено. Пример вызова процедуры (использование пакета):

```plsql
BEGIN
  IF un$fm.use_fm THEN
    msg(1);
  END IF;
END;
```
