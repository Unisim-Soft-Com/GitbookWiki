# Apache

Запрос по HTTP приводит к генерации PL/SQL‑блока, который исполняется в контексте веб‑схемы, соответствующей имени в URL. В ответ просто возвращается то, что вернулось из PL/SQL.

Особенность: для каждого запроса не открывается новая сессия Oracle — PHP использует пул соединений, поэтому не тратится время на выделение ресурсов при каждом запросе. Кроме того, работает HTTP keep‑alive.

Схемы не добавляются вручную — в URL указывается имя схемы (это действует только на oravirt; у клиентов оставляем однозначно, во избежание). По указанному имени просто прилепляется суффикс "web" и выполняется логин.

Интерфейса добавления DAD‑ов через Apache/PHP нет и не будет — и так всё работает с костылями. Если нужен интерфейс — PL/SQL Gateway всё ещё работает, и там соответствующая страница доступна; этот интерфейс изначально и предназначен для PGW.

Для разрешения использования схем через Apache/PHP возможно потребуется правка регулярных выражений в файле:

```
/var/www/html/.htaccess
```

а также, в зависимости от древности файлов, правка:

```
/var/www/html/orders/conn.php
```
