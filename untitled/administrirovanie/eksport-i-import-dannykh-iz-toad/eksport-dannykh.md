# Экспорт данных

{% stepper %}
{% step %}
### Запустить программу toad и подключиться к нужной схеме (Dev @oratest)

В верхней строке меню найдите Database и выберите Database -> Export -> Export Utility Wizard.

![](<../../.gitbook/assets/image (296)>)
{% endstep %}

{% step %}
### Выбрать Экспорт таблицы

Выберите "Экспорт таблицы (Export tables)" из следующих опций и нажмите Далее.

![](<../../.gitbook/assets/image (297)>)
{% endstep %}

{% step %}
### Выбрать таблицы для экспорта

Выберите доступные пользователю таблицы, которые нужно экспортировать, и нажмите Далее.

![](<../../.gitbook/assets/image (298)>)
{% endstep %}

{% step %}
### Установить параметры экспорта

Выставьте нужные параметры (в примере оставлены значения по умолчанию) и нажмите Далее (Next).

![](<../../.gitbook/assets/image (299)>)
{% endstep %}

{% step %}
### Указать каталог для сохранения экспортированных файлов

На открывшейся вкладке напротив "output file name" нажмите кнопку для указания пути и имени файла. В примере выбрана папка на рабочем столе с именем test и имя файла тоже test.

![](<../../.gitbook/assets/image (300)>)

После сохранения вы увидите, что создалось три файла — нажмите Далее (Next), затем кнопку Готово (Finish).

![](<../../.gitbook/assets/image (301)>)

После экспорта данных создаются файлы для дальнейшего использования.
{% endstep %}
{% endstepper %}
