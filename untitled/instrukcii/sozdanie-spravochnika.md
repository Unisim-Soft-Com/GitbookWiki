# Создание справочника

Создадим специальный справочник типа `P TVR` для торговли — дизайн этого справочника будет отличаться от стандартного `vms_univers` и настроен на другую вьюху.

{% stepper %}
{% step %}
### Дублирование узла в конфигураторе

1. Откройте конфигуратор.
2. Выберите раздел `Univ List -> Univ group -> UnivTip_P` и продублируйте любой узел.
{% endstep %}

{% step %}
### Экспорт и импорт узла

1. Выберите любой узел в группе `UnivTip_P`.
2. Щелкните по нему правой кнопкой мыши, в контекстном меню выберите `Data -> Export -> Node`.
3. Затем щелкните правой кнопкой мыши по `UnivTip_P`, в контекстном меню выберите `Data -> Import -> New SubNode`.
{% endstep %}

{% step %}
### Задание свойств нового узла

В новом узле задайте свойства:

* Caption: `UnivList P:TVR:Trade`
* Section: `UNIVLIST : P : TRADE`

Пояснение к именам:

* Имя в `Caption` задается по правилу: `UnivList` Тип:`Атрибут(GR1):ID` — значение `ID` придумывается по смыслу использования справочника (можно задать любое имя).
* Имя `Section` задается как `UNIVLIST:Тип:ID` (можно задать любое имя секции).
{% endstep %}
{% endstepper %}

![Шаги: экспорт/импорт узла](<../.gitbook/assets/image (583)>)

Ниже — минимальный набор свойств узла и значения для примера:

| Имя свойства  | Тип     | Описание                | Значение для примера |
| ------------- | ------- | ----------------------- | -------------------- |
| Active        | Boolean |                         | true                 |
| Caption       | String  | Справочник для торговли |                      |
| Gr1           | String  |                         | TVR                  |
| ID            | String  |                         | Trade                |
| SagiEditQuery | Boolean |                         | true                 |

{% hint style="info" %}
Чтобы справочник выпадал в UNA по Alt+D — убедитесь, что соответствующие свойства и секции заданы правильно.
{% endhint %}
