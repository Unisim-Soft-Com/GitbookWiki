# SF (1222) НН с оплатой по перечислению

Для продажи товара по перечислению рекомендуется пользоваться документом (1222) НН с оплатой по перечислению. Первоначально необходимо указать дату продажи — дату документа и заполнить шапочную часть накладной.

{% stepper %}
{% step %}
### Заполнить шапку накладной

Укажите дату продажи (дату документа) и заполните шапочную часть накладной.

![](<../../.gitbook/assets/image (614)>)
{% endstep %}

{% step %}
### Добавить товар в табличную часть

Чтобы добавить выбранный товар в нижнюю табличную часть:

* нажмите на клавишу **+**;
* укажите нужное количество для продажи и нажмите **Enter**;
* по завершению набора списка необходимого товара нажмите повторно **Enter** или кнопку **ОК** в правой нижней части окна.

![](<../../.gitbook/assets/image (615)>)
{% endstep %}

{% step %}
### Рассчитать накладную и распечатать

Выполните действие "Рассчитать накладную" для формирования проводок в документе. После этого распечатайте печатную форму налоговой накладной.

![](<../../.gitbook/assets/image (616)>)

![](<../../.gitbook/assets/image (617)>)
{% endstep %}
{% endstepper %}
