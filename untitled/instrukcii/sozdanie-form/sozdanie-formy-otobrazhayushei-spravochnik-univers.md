# Создание формы отображающей справочник Univers

В конфигураторе выберите узел: Forms -> Forms group -> Формы - Тест

![Выбор узла](<../../.gitbook/assets/image (722)>)

{% stepper %}
{% step %}
### Добавление подузла — форма Univers

Выделите узел "Формы - Тест" и в меню выберите Add subnode. В открывшемся окне выберите Forms и нажмите Ок. Введите имя: "Форма Univers".

![Добавление подузла](<../../.gitbook/assets/image (723)>)
{% endstep %}

{% step %}
### Настройка свойств формы

В конфигураторе выберите созданный подузел и задайте свойства формы. Пример значений:

| Название свойства | Тип     | Описание                    | Значение для примера |
| ----------------- | ------- | --------------------------- | -------------------- |
| Active            | Boolean | действующий объект          | true                 |
| Caption           | Boolean | подпись формы               | Форма Univers        |
| DLL FormName      | String  | тип формы                   | Univers              |
| DLL ID            | Integer | идентификационный номер DLL | 0                    |
| TIP               | String  | тип справочника SysS        | T                    |
| GR1               | String  | подгруппа справочника GR1   | AVTO                 |
| GR2               | String  | подгруппа справочника GR2   |                      |

В конфигураторе это выглядит так:

![Свойства формы](<../../.gitbook/assets/image (724)>)

Обязательно нажмите Commit (красную галочку).
{% endstep %}

{% step %}
### Обновление UNE и открытие формы

В Une нажмите F5 (Обновить). В меню формы появится наш справочник.

![Пункт меню формы](<../../.gitbook/assets/image (725)>)

Выбрав "Форма Univers" откроется справочник T AVTO, который можно дальше настраивать.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Если привязка справочника в UNE к унивЛисту в конфигураторе не работает, причиной может быть пустое свойство Active или его отсутствие. В конфигурационном файле должно быть, например:

```
[ZZZ]
Active=true
.type.Active=Boolean
```
{% endhint %}
