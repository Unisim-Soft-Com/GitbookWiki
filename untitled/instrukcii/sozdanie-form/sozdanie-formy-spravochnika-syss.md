# Создание формы справочника SysS

В конфигураторе выбираем узел `Forms -> Forms group -> Формы-Тест`

![](<../../.gitbook/assets/image (784)>)

В этот узел добавим новый узел — форму, которая будет отображать данные из справочника `SysS`.

{% stepper %}
{% step %}
### Добавление подузла формы

Выделяем узел `Формы-Тест` и в меню выбираем **Add subnode**, в открывшемся окне выбираем **Forms**.

![](<../../.gitbook/assets/image (785)>)

Нажимаем Ок и вводим имя: `Форма SysS`.

После этого в конфигураторе в узел `Формы-Тест` добавится подузел `Форма SysS`.
{% endstep %}

{% step %}
### Настройка свойств формы

Настройте свойства формы следующим образом:

| Название свойства | Тип     | Описание                    | Значение для примера |
| ----------------- | ------- | --------------------------- | -------------------- |
| Active            | Boolean | действующий объект          | true                 |
| Caption           | Boolean | подпись формы               | Маршруты             |
| DLL FormName      | String  | тип формы                   | SysS                 |
| DLL ID            | Integer | идентификационный номер DLL | 0                    |
| TIP               | String  | тип справочника SysS        | S                    |
| TIP.COD           | String  | подгруппа справочника GR1   | 79                   |

Пример в конфигураторе:

![](<../../.gitbook/assets/image (786)>)

Не забудьте нажать **Commit** (красную галочку).
{% endstep %}

{% step %}
### Обновление UNE и проверка

В UNE нажимаем F5 (Обновить).

В меню формы появится наш справочник `Форма SysS`.

![](<../../.gitbook/assets/image (787)>)

Выбрав `Форма SysS`, откроется справочник `S 79`, который можно дальше настраивать.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Если не работает привязка справочника в УНЕ к унивЛисту в конфигураторе, причиной может быть пустое свойство `Active` или его отсутствие. Например, добавьте/проверьте следующие строки в конфигурации:

```
[ZZZ]
Active=true
.type.Active=Boolean
```
{% endhint %}
