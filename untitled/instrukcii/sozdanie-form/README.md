# Создание форм

Формы реализуют интерфейс работы с определенными данными. Настройка существующих и новых форм включает интерфейсную часть и часть обработки данных.

Формы служат для работы пользователя со специализированной справочной информацией либо для выполнения определенных действий с данными.

Открытие формы производится выбором соответствующего пункта меню Формы.

![Меню Формы](<../../.gitbook/assets/image (587)>)

О свойствах формы можно почитать по ссылке: https://bsoft.gitbook.io/wiki/razrabotka/konfigurator/formy

Добавим к конфигуратору тестовый узел, в котором будем создавать формы. В конфигураторе выбираем узел Forms -> Forms group (щелкните правой кнопкой мыши по Forms group) и выберите на панели Add subnode.

{% step %}
### Выбор узла и добавление подузла

В конфигураторе выберите узел Forms -> Forms group (щелкните правой кнопкой мыши по Forms group) и на панели нажмите "Add subnode".

![Добавить подузел](<../../.gitbook/assets/image (588)>)

![Панель Add subnode](<../../.gitbook/assets/image (589)>)
{% endstep %}

{% step %}
### Выбор типа создаваемой группы

В открывшемся окне выберите группу "Forms groups" и нажмите OK.

![Выбор группы Forms groups](<../../.gitbook/assets/image (590)>)
{% endstep %}

{% step %}
### Ввод имени группы

В открывшемся окне введите имя узла группы форм. В примере вводим: "Формы - Тест", затем нажимаем Ок.

![Ввод имени узла групп](<../../.gitbook/assets/image (591)>)
{% endstep %}

{% step %}
### Результат

В конфигураторе появится новый узел "Формы - Тест".

![Новый узел в конфигураторе](<../../.gitbook/assets/image (592)>)
{% endstep %}
{% endstepper %}
