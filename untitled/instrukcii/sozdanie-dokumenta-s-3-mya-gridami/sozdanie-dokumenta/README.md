# Создание документа

### **7 Создание документа** <a href="#id-7-sozdanie-dokumenta" id="id-7-sozdanie-dokumenta"></a>

Запускаем клиент программы Universal Accounting **uniacCLNT.exe**.

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-b5f4d41e712a68ec6b2a65bf6e8202233ecc64f3%252Fscreenshot099.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=797bf9c3&#x26;sv=2" alt=""><figcaption></figcaption></figure>

В открывшемся окне вводим имя сервера, имя и пароль для доступа в программу и имя и пароль схемы (если пароль совпадает с именем схемы, его можно не заполнять) и нажимаем

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-ebc449de3ee7abaab1bdf1acb875771eab26d0cf%252Fok10.png%3Falt%3Dmedia\&width=768\&dpr=4\&quality=100\&sign=b36820e2\&sv=2)

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-2e58c21c74edb630b494ba1ced8d31c71b3e1775%252Fscreenshot100.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=5a08bf13&#x26;sv=2" alt=""><figcaption></figcaption></figure>

Для того, чтобы документ созданный в конфигураторе появился в списке воспользуемся горячей клавишей **F5**. В открывшемся окне нажимаем кнопку

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-81f93d68d2dbfc585f4610880c2a5973163c8410%252Fyes%2520%284%29.png%3Falt%3Dmedia\&width=768\&dpr=4\&quality=100\&sign=ac8e10a8\&sv=2)

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-1e4002684b4724d98625f3299521e9ec5d1a86c7%252Fscreenshot317.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=f733475c&#x26;sv=2" alt=""><figcaption></figcaption></figure>

После обновления настроек появится окно об успешном обновлении настроек. Нажимаем кнопку

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-36cece0beaf0d3c47cafd4c3329f0dba37808396%252Fscreenshot320.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=28aabf9c&#x26;sv=2" alt=""><figcaption></figcaption></figure>

Далее нажимаем на кнопку

![](https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-9a89cd07cd197297b3e3895a0392ebea19dd0b69%252Fnovyi%2520%281%29.png%3Falt%3Dmedia\&width=768\&dpr=4\&quality=100\&sign=25aaf44d\&sv=2)

и по полю _ID_ ищем уникальный номер, который мы записали в конфигураторе в поле _DB ID_.

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-58ae80ed456e7529b83e40c404272b0f18793fc3%252Fscreenshot101.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=217c7231&#x26;sv=2" alt=""><figcaption></figcaption></figure>

Можно воспользоваться поиском, начиная вводить цифры, находясь в поле ID.

<figure><img src="https://unisim-soft.gitbook.io/wiki/~gitbook/image?url=https%3A%2F%2F1551963169-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fdpxmw8hXT3TeLEAjCF7m%252Fuploads%252Fgit-blob-0218789da4a601e59375f9fa7bb81168538a272d%252Fscreenshot102.png%3Falt%3Dmedia&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=b7027ec8&#x26;sv=2" alt=""><figcaption></figcaption></figure>
