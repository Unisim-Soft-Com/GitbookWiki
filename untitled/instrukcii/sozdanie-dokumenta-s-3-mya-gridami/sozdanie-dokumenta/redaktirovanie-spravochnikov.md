# Редактирование справочников

{% stepper %}
{% step %}
### Открыть редактирование шапки

Для редактирования справочников в шапке нажмите горячие клавиши Ctrl + ПКМ (или клик ролика мыши, находясь в области шапки).

![](<../../../.gitbook/assets/image (895)>)

или

![](<../../../.gitbook/assets/image (896)>)
{% endstep %}

{% step %}
### Настройка UnDBEdit1 — справочник организаций

1. Нажмите на `UnDBEdit1`, в поле DataField выберите любое вычисляемое (CLC) текстовое (T) поле.

![](<../../../.gitbook/assets/image (897)>)

2. Нажмите на кнопку с многоточием для настройки справочника:

![](<../../../.gitbook/assets/image (898)>)

3. На вкладке настройки заполните поля:

* Data field автоматически установит поле между CLC и T (в примере — DTSC0).
* Выберите поле Denumirea справочника `TMS_UNIVERS`.
* Attribute = 0, Grouping = E (External).

4. Нажмите ОК и сохраните редактирование перед выходом с помощью галочки и кнопки подтверждения.

![](<../../../.gitbook/assets/image (899)>)

![](<../../../.gitbook/assets/image (900)>)

![](<../../../.gitbook/assets/image (901)>)

В результате в поле `UnDBEdit1` будет справочник с организациями.

![](<../../../.gitbook/assets/image (902)>)
{% endstep %}

{% step %}
### Настройка UnDBEdit2 — справочник внутренних отделов

1. Войдите в дизайн шапки (горячая клавиша — клик ролика мыши в области шапки).

![](<../../../.gitbook/assets/image (903)>)

2. Нажмите на `UnDBEdit2`, в DataField выберите вычисляемое (CLC) текстовое (T) поле.

![](<../../../.gitbook/assets/image (904)>)

3. Нажмите многоточие для настройки справочника и на вкладке заполните:

* Attribute = O, Grouping = I (Internal).
* Выберите поле Denumirea справочника `TMS_UNIVERS`.
* Data field заполнится автоматически.

![](<../../../.gitbook/assets/image (905)>)

4. Нажмите ОК и сохраните редактирование перед выходом.

![](<../../../.gitbook/assets/image (906)>)

![](<../../../.gitbook/assets/image (907)>)

Теперь в `UnDBEdit2` будет справочник с внутренними отделами организации.

![](<../../../.gitbook/assets/image (908)>)
{% endstep %}

{% step %}
### Настройка Grid №1 — поле "Наименование блюд" (CLCDISHT)

1. Откройте дизайн Grid'a №1 (горячая клавиша Alt+D).
2. Выделите колонку `CLCDISHT`. В поле Data field автоматически вставится слово между CLC и T.

* Attribute = P (Product)
* Grouping = TVRIKUH (Товар Кухни)
* Выберите поле Denumirea и сохраните изменения перед выходом.

![](<../../../.gitbook/assets/image (909)>)

3. Нажмите ОК.

![](<../../../.gitbook/assets/image (910)>)

В результате в поле Наименование блюд (`CLCDISHT`) будет выпадающий справочник с блюдами.

![](<../../../.gitbook/assets/image (911)>)
{% endstep %}

{% step %}
### Настройка Grid №2 — поле "Наименование продуктов" (CLCPRODUCTT)

1. Откройте дизайн Grid'a №2 (Alt+D).
2. Выделите колонку `CLCPRODUCTT`. В поле Data field автоматически вставится слово между CLC и T.

* Attribute = P (Product)
* Grouping = TVRB (Товар)
* Выберите поле Denumirea и сохраните изменения перед выходом.

![](<../../../.gitbook/assets/image (912)>)

3. Нажмите ОК.

![](<../../../.gitbook/assets/image (913)>)

В результате в поле "Наименование продуктов" (`CLCPRODUCTT`) будет выпадающий справочник с продуктами для приготовления блюд.

![](<../../../.gitbook/assets/image (914)>)

![](<../../../.gitbook/assets/image (915)>)
