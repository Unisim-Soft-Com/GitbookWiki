# Редактирование дизайна

### 7.2 Редактирование дизайна

{% hint style="info" %}
Горячие клавиши:

* Открыть окно дизайна: Alt+D
* Редактирование шапки: Ctrl + ПКМ
{% endhint %}

Открываем дизайн (Alt+D). В правой части находятся поля из шаблона, в левой — сформированные колонки из вида (View) `YVEINE_VMDB_INTAKE_LIST_A`. Колонки из левой части необходимо перенести в правую, а колонки из правой — в левую (при следующем вызове окна дизайна их не будет).

![](<../../../.gitbook/assets/image (622)>)

Для переноса колонок можно использовать двойной клик ЛКМ или кнопки управления переносом:

![](<../../../.gitbook/assets/image (623)>)

![](<../../../.gitbook/assets/image (624)>)

![](<../../../.gitbook/assets/image (625)>)

![](<../../../.gitbook/assets/image (626)>)

После переноса сохраняем изменения при выходе, поставив галочку и нажав кнопку OK / Save on exit:

![](<../../../.gitbook/assets/image (627)>)

В результате появятся колонки из вида (View) `YVEINE_VMDB_INTAKE_LIST_A`, который находится на вкладке:

### Редактирование Grid №1 — перенос и настройка колонок

1. Откройте окно дизайна (Alt+D).
2. Перенесите колонки слева направо и справа налево (двойной клик или кнопки переноса).
3. Сохраните изменения при выходе (поставьте галочку и нажмите OK).

После переноса задаём имя и размеры колонок:

* Поле ID — Caption: "Код"
* Поле DATA — Caption: "Дата"
* Поле CANT1 — Caption: "Передано"
* Поле CANT2 — Caption: "Возвращено"
* Поле CANT3 — Caption: "Итого кол-во"
* Поле CLCDISHT — Caption: "Наименование блюд"

### Редактирование Grid №2

1. Откройте окно дизайна (Alt+D).
2. Поменяйте местами колонки (перенос слева-направо и справа-налево).

### Редактирование шапки документа

1. Для редактирования шапки используйте Ctrl + ПКМ — в появившемся меню выберите пункт Design (Дизайн).

![](<../../../.gitbook/assets/image (639)>)

2. Создайте статические подписи ("Static Text") для надписей, например «Получатель» и «Цех-производитель»:

* Нажмите кнопку создания нового элемента (Create New) для Static Text и разместите элемент в шапке.
* Повторите для второго Static Text.

![](<../../../.gitbook/assets/image (640)>)

3. Создайте поля справочников (UnDBEdit) рядом с этими надписями:

* В списке элементов выберите UnDBEdit и разместите его рядом с Static Text.
* Создайте второй UnDBEdit аналогично.

![](<../../../.gitbook/assets/image (641)>)

4. Задайте подписи Static Text через поле Caption, например "Получатель:" и "Цех-производитель:".

![](<../../../.gitbook/assets/image (642)>)

5. Сохраните результат при выходе (галочка + OK).

![](<../../../.gitbook/assets/image (643)>)

### Настройка внешнего вида колонок (шрифт, цвет, выравнивание и т. п.)

* Поле Caption — имя колонки.
* Поле Height — высота колонки.
* Поле Width — ширина колонки.

![](<../../../.gitbook/assets/image (644)>)

* Для изменения шрифта нажмите кнопку Font и настройте параметры в открывшемся окне.

![](<../../../.gitbook/assets/image (645)>)

![](<../../../.gitbook/assets/image (646)>)

* Для изменения цвета колонки нажмите кнопку Color и выберите нужный цвет в появившемся окне.

![](<../../../.gitbook/assets/image (647)>)

![](<../../../.gitbook/assets/image (648)>)

В окне Preview можно увидеть результат изменения (пример: полужирный шрифт и жёлтый фон).

![](<../../../.gitbook/assets/image (649)>)

* Для выравнивания текста используйте кнопку выравнивания по центру — текст будет расположен по центру колонки.

![](<../../../.gitbook/assets/image (650)>)

![](<../../../.gitbook/assets/image (651)>)
