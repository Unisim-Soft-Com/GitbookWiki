# Экспорт/Импорт шаблона документа в конфигураторе

### 6 Экспорт/Импорт шаблона документа в конфигураторе

Таблицы, виды, последовательность и триггеры созданы, но для того чтобы создать документ необходимо в конфигураторе сделать следующее:

{% stepper %}
{% step %}
### Запуск конфигуратора и подключение

Запустите файл uniConf.exe.

![](<../../.gitbook/assets/image (846)>)

Заполните поля Home, Server, User name и Password. (Если имя схемы совпадает с паролем, то пароль можно не заполнять). Далее нажмите ОК.

![](<../../.gitbook/assets/image (847)>)

В появившемся окне введите имя пользователя и пароль для доступа к программе и нажмите ОК.

![](<../../.gitbook/assets/image (848)>)

![](<../../.gitbook/assets/image (849)>)
{% endstep %}

{% step %}
### Выбор шаблонного документа и экспорт поддерева

Выберите шаблонный документ в дереве.

![](<../../.gitbook/assets/image (850)>)

Нажмите кнопку создания нового узла и выберите из списка Export-SubTree. В результате будет экспортировано поддерево (включая Actions и Print Forms).

![](<../../.gitbook/assets/image (851)>)

![](<../../.gitbook/assets/image (852)>)

Дождитесь сообщения о завершении экспорта и подтвердите его.

![](<../../.gitbook/assets/image (853)>)

![](<../../.gitbook/assets/image (854)>)
{% endstep %}

{% step %}
### Выбор группы документов для импорта и импорт

Выберите группу документов, в которую необходимо выполнить импорт.

![](<../../.gitbook/assets/image (855)>)

Нажмите создание нового узла и выберите Import-New Subnode.

![](<../../.gitbook/assets/image (856)>)

![](<../../.gitbook/assets/image (857)>)

Дождитесь сообщения о завершении импорта и подтвердите его.

![](<../../.gitbook/assets/image (858)>)
{% endstep %}

{% step %}
### Присвоение уникального DB ID

В колонку DB ID запишите уникальное значение. Для этого двойным щелчком ЛКМ кликните на колонку DB ID. В появившемся окне напротив Value введите уникальное значение и подтвердите ОК.

![](<../../.gitbook/assets/image (859)>)

![](<../../.gitbook/assets/image (860)>)

![](<../../.gitbook/assets/image (861)>)
{% endstep %}

{% step %}
### Очистка данных кастомизации

Перейдите на вкладку Customization. Здесь вы увидите заполненные данные, относящиеся к документу, с которого был произведён экспорт. Эти данные необходимо удалить сочетанием клавиш Ctrl+Delete.

![](<../../.gitbook/assets/image (862)>)

После удаления поля будут очищены.

![](<../../.gitbook/assets/image (863)>)

![](<../../.gitbook/assets/image (864)>)
{% endstep %}

{% step %}
### Сохранение изменений (Commit)

После всех проделанных действий сохраните изменения в транзакции кнопкой Commit.

![](<../../.gitbook/assets/image (865)>)

![](<../../.gitbook/assets/image (866)>)
{% endstep %}
{% endstepper %}
